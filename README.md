# WonderStay

<h2>TE Project</h2>
<p><h3>Project Title</h3>
WonderStay –  Hotel & Resort Booking & Recommendation System

<h3>Project Type</h3>
Web Application | Academic Project

<h3>Project Description</h3>
WonderStay is a hotel and resort booking platform designed specifically for the Indian travel market. The system provides separate interfaces for users and property owners, where users can search, compare, and book hotels or resorts, and owners can register and manage their properties.

The platform uses  recommendation algorithms to suggest nearby stays, budget-friendly options, and season-wise best destinations in India. Dynamic pricing algorithms adjust accommodation prices based on demand, location, season, and availability. A location API enables accurate geo-based search, making the system practical for real-world travel planning.

<h3>Key Features</h3>
Separate login and dashboards for Users and Hotel/Resort Owners

Owner registration and property listing management

Budget-friendly filtering based on user-selected price range

Season-wise destination recommendation (e.g., hill stations in summer, beaches in winter)

Indian location–based listing and city-wise categorization

Dynamic pricing using demand, season, and location-based algorithms

Location API integration for geo-based search

User booking, rating, and review system

Secure authentication and booking workflow

<h3>Technologies Used</h3>
Backend: express.js, node.js

Frontend: HTML, CSS, JavaScript

Database: mongodb

<h3>Algorithms:</h3>

Recommendation algorithms (nearby, budget, rating-based)

Season-aware recommendation logic

Demand-based dynamic pricing algorithms

APIs: Location API for distance and geo-coordinates
